# Иван Зубов — недвижимость с личным подходом

Приватный проект сайта-визитки риэлтора в Москве. Первая версия — локальный интерактивный макет для согласования.

## Запуск

Требуется Node.js 20 или новее. Зависимостей нет.

```sh
npm run dev
```

Откройте http://localhost:4173. Для переноса статической версии: `npm run build` (результат в `dist/`). На Windows, если PowerShell блокирует `npm.ps1`, используйте `npm.cmd run dev`.

Проверки: `npm run check` и `npm test`. Сервер отдаёт только файлы сайта, не открывая служебные файлы проекта; поддерживает запросы диапазонов для видео.

## Контент

Цены, кейсы, отзывы, показатели, полная биография и контакты хранятся в `content.mjs`. Округа и описания — в `okrugs.mjs`. Заголовки разделов и короткий вводный текст — в `index.html`. Отзывы и портрет предоставлены Иваном; кейсы, показатели и цены пока демонстрационные. Архитектурные материалы стоковые и не изображают реальные объекты Ивана.

`map.mjs` управляет реальной картой Москвы на Leaflet: 12 административных округов, включая Зеленоград и Новую Москву. Выбор — нажатием на границу или метку округа; доступны масштаб, перемещение и возврат «Вся Москва». Поиск и отдельный список убраны по пожеланию пользователя. Метки поддерживают выбор клавиатурой. Курсор — небольшой круг 26 px без текста. Для каждого округа подобрана отдельная локальная фотография реального места с указанием автора и лицензии. Для картографической подложки нужен интернет; границы и фото локальные. Контактная кнопка передаёт выбранный округ в черновик Telegram: [официальная документация](https://core.telegram.org/api/links#public-username-links).

## Публикация в Vercel и CI/CD

Настройки сборки сохранены в `vercel.json`: перед публикацией выполняются проверка синтаксиса, тесты и сборка. Vercel публикует только `dist/`. Сбой любой проверки останавливает публикацию этой версии.

GitHub Actions (`.github/workflows/ci.yml`) проверяет изменения при push и в pull request на Node.js 22 и 24. Секреты для проверок не нужны. Автоматическая публикация на Vercel работает после подключения репозитория `Vinishk0/ivan-zubov-realestate` в настройках проекта Vercel: изменения веток получают Preview-ссылки, а выбранная Production Branch обновляет постоянный адрес. Текущая версия сайта находится в `codex/color-full-portrait`; перед первой публикацией нужно выбрать эту ветку, поскольку `main` содержит более раннюю версию.

Для закрытой разработки **до первой публикации** включите Vercel Authentication → All Deployments в Settings → Deployment Protection. Это защищает также постоянный адрес сайта. Для показа без аккаунта Vercel создайте Shareable Link; ссылка даёт доступ любому, кто её получил, и может быть отозвана в Vercel. Не сохраняйте такую ссылку в репозитории. Защита доступа управляется в Vercel, а не через `vercel.json`.

Индексация дополнительно запрещена через meta robots, `robots.txt` и HTTP-заголовок `X-Robots-Tag`. Эти запреты сами по себе не ограничивают доступ посетителей. Когда сайт будет готов к публичному запуску, отдельно пересмотрите защиту доступа и все три запрета индексации.
