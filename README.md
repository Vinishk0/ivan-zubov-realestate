# Иван Зубов — недвижимость с личным подходом

Приватный проект сайта-визитки риэлтора в Москве. Первая версия — локальный интерактивный макет для согласования.

## Запуск

Требуется Node.js 20 или новее. Зависимостей нет.

```sh
npm run dev
```

Откройте http://localhost:4173. Для переноса статической версии: `npm run build` (результат в `dist/`). На Windows, если PowerShell блокирует `npm.ps1`, используйте `npm.cmd run dev`.

Проверки: `npm run check` и `npm test`. Сервер отдаёт только файлы сайта, не открывая служебные файлы проекта; поддерживает запросы диапазонов для видео.

## Контент

Цены, кейсы, отзывы, показатели, полная биография и контакты хранятся в `content.mjs`. Районы и описания — в `districts.mjs`. Заголовки разделов и короткий вводный текст — в `index.html`. Все кейсы, отзывы, показатели и цены демонстрационные. Портрет и архитектурные материалы стоковые и не изображают Ивана или его объекты.

`map.mjs` управляет реальной картой Москвы на Leaflet: 132 района в 12 округах, включая Зеленоград и Новую Москву. Доступны поиск (в том числе без «ё» и по названию «Пресня»), фильтр по округу, выбор в списке и на карте, приближение, перемещение и возврат «Вся Москва». Enter выбирает первый результат поиска. Подпись на карте показана только у выбранного района. Курсор — небольшой круг 26 px без текста. У пяти первоначальных районов свои реальные фотографии; остальные пока используют общую фотографию Москвы по решению пользователя.
