# Иван Зубов — недвижимость с личным подходом

Приватный проект сайта-визитки риэлтора в Москве. Первая версия — локальный интерактивный макет для согласования.

## Запуск

Требуется Node.js 20 или новее. Зависимостей нет.

```sh
npm run dev
```

Откройте http://localhost:4173. Для переноса статической версии: `npm run build` (результат в `dist/`).

## Контент

Тексты, цены, кейсы, отзывы и контактные данные будут храниться в `content.mjs`. Все кейсы, отзывы, показатели и цены демонстрационные. Портрет и архитектурные материалы стоковые и не изображают Ивана или его объекты.
