# Иван Зубов — недвижимость с личным подходом

Приватный проект сайта-визитки риэлтора в Москве. Первая версия — локальный интерактивный макет для согласования.

## Запуск

Требуется Node.js 20 или новее. Зависимостей нет.

```sh
npm run dev
```

Откройте http://localhost:4173. Для переноса статической версии: `npm run build` (результат в `dist/`). На Windows, если PowerShell блокирует `npm.ps1`, используйте `npm.cmd run dev`.

Проверки: `npm run check` и `npm test`. Сервер отдаёт только файлы сайта, не открывая служебные файлы проекта; поддерживает запросы диапазонов для видео.

## Контент

Цены, кейсы, отзывы, показатели, полная биография и контакты хранятся в `content.mjs`. Округа и описания — в `okrugs.mjs`. Заголовки разделов и короткий вводный текст — в `index.html`. Все кейсы, отзывы, показатели и цены демонстрационные. Портрет и архитектурные материалы стоковые и не изображают Ивана или его объекты.

`map.mjs` управляет реальной картой Москвы на Leaflet: 12 административных округов, включая Зеленоград и Новую Москву. Выбор — нажатием на границу или метку округа; доступны масштаб, перемещение и возврат «Вся Москва». Поиск и отдельный список убраны по пожеланию пользователя. Метки поддерживают выбор клавиатурой. Курсор — небольшой круг 26 px без текста. Округа пока используют общую фотографию Москвы. Для картографической подложки нужен интернет; границы и фото локальные. Контактная кнопка передаёт выбранный округ в черновик Telegram: [официальная документация](https://core.telegram.org/api/links#public-username-links).
