# Иван Зубов — недвижимость с личным подходом

Приватный проект сайта-визитки риэлтора в Москве. Первая версия — локальный интерактивный макет для согласования.

## Запуск

Требуется Node.js 20 или новее. Зависимостей нет.

```sh
npm run dev
```

Откройте http://localhost:4173. Для переноса статической версии: `npm run build` (результат в `dist/`). На Windows, если PowerShell блокирует `npm.ps1`, используйте `npm.cmd run dev`.

Проверки: `npm run check` и `npm test`. Сервер отдаёт только файлы сайта, не открывая служебные файлы проекта; поддерживает запросы диапазонов для видео.

## Контент

Цены, кейсы, отзывы, показатели, описания районов, полная биография и контакты хранятся в `content.mjs`. Заголовки разделов и короткий вводный текст — в `index.html`. Все кейсы, отзывы, показатели и цены демонстрационные. Портрет и архитектурные материалы стоковые и не изображают Ивана или его объекты.

`map.mjs` управляет реальной картой Москвы на Leaflet: границы пяти районов из OpenStreetMap, выбор района, приближение и перемещение, синхронизация маркеров и кнопок. Курсор — небольшой круг 26 px без текста. Фотографии районов реальные, с указанием авторов и лицензий. Для картографической подложки нужен интернет; границы и фото локальные.
