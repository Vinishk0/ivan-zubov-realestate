# Отзывы с модерацией VK

Кнопка «Оставить отзыв» отправляет имя и текст на /api/reviews. Отзыв сохраняется со статусом pending и отправляется сообществом VK с двумя callback-кнопками. Только опубликованные отзывы доступны публичному API и добавляются к существующим отзывам. Повторное открытие вкладки загружает новые отзывы.

Для включения:
1. Подключите постоянное Redis-хранилище с REST API (например Upstash). Укажите REVIEWS_REDIS_URL, REVIEWS_REDIS_TOKEN; для теста и production используйте разные REVIEWS_NAMESPACE.
2. Укажите токен сообщества VK, числовой VK_PEER_ID (для теста VK_TEST_PEER_ID), VK_GROUP_ID и VK_REVIEW_MODERATOR_IDS — числовые ID пользователей, которым разрешена модерация.
3. В Callback API сообщества задайте HTTPS-адрес /api/vk-callback, секрет VK_CALLBACK_SECRET и код подтверждения VK_CALLBACK_CONFIRMATION. Включите события message_event. Токену нужно право messages; модератор должен разрешить сообщения сообщества.
4. Проверьте сценарий в тестовом окружении: отправить отзыв, убедиться в отсутствии на сайте, одобрить в VK и обновить страницу. Повторите с отклонением. Затем включите production с VK_TEST_MODE=false.

Новые записи не публикуются автоматически. Ожидающие и отклонённые записи удаляются через 30 дней; опубликованные хранятся постоянно. Публичная выдача ограничена последними 100 отзывами. Недоступное хранилище не скрывает существующие отзывы и не выдаёт ложного подтверждения отправки. Ограничение отправок хранится в Redis (3 за 10 минут с IP). Тексты отображаются как текст, HTML не исполняется.

Автотесты используют подмены VK и хранилища, реальных сообщений не отправляют. Живая интеграция требует настроенных секретов и опубликованного HTTPS callback.
