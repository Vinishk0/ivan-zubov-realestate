# Дизайн: редакционная версия

Ветка: `codex/editorial-redesign`. Основа: `codex/auction-service-case-photo`.

Светлая палитра, чернильный акцент, крупная типографика и три равноправные карточки кейсов. По обратной связи возвращены полноэкранная видеообложка и прежний блок знакомства. Удалена ссылка «Покупка / Продажа / Торги» после обложки. Цифры достижений центрированы над подписями. Убраны переключатель палитр, блок настроений и повторяющиеся рекламные секции. Принципы работы доступны в раскрывающемся блоке; все семь показателей сохранены. Услуги сведены в единый список с ценами и пояснениями, подробности открываются в диалоге.

`content.mjs` не изменён: все кейсы, цены, отзывы и контакты сохранены. Карта округов работает как прежде. Видео получило кнопку паузы и учитывает reduced motion. Стили этой версии находятся в существующем `portrait-color.css`, после базового `styles.css`.

Проверено: синтаксис JavaScript, 9 существующих тестов, статическая сборка. В браузере проверены три кейса, шесть услуг, биография, принципы работы, переключение и полный текст отзыва, FAQ, выбор округа с передачей в Telegram, мобильное меню. На ширинах 390 и 1440 CSS px нет горизонтального переполнения, изображения загрузились, ошибок консоли не обнаружено.

Просмотр: `npm.cmd run dev`, затем http://localhost:4173. Публикация не выполнялась.
