# Заявки сайта → VK

Форма отправляет JSON на `/api/leads`. Сервер проверяет данные и вызывает `messages.send` с ключом сообщества. Успех показывается только после подтверждения VK; заявки не имитируются и не сохраняются в браузере.

## Подключение

1. Включите сообщения сообщества VK и создайте ключ с разрешением на сообщения.
2. Иван должен разрешить сообщения от сообщества (например, сначала написать ему). Для беседы добавьте сообщество и разрешите ему отправку сообщений.
3. В настройках серверного окружения Vercel задайте `VK_COMMUNITY_TOKEN` и `VK_PEER_ID`. Для личных сообщений — числовой ID Ивана; для беседы — её peer ID. Переменные должны быть доступны нужному окружению Preview / Production. После изменения выполните повторное развёртывание.
4. Локально скопируйте `.env.example` в `.env.local`, заполните значения и перезапустите `npm run dev`. `.env.local` исключён из Git и недоступен через локальный HTTP-сервер.
5. Отправьте тестовую заявку с сайта и проверьте уведомление у Ивана. Пока токен и получатель не настроены, форма сообщает об этом и предлагает прямую связь.

Получатель задаётся только на сервере; посетитель не может отправить сообщение другому пользователю. Ключ не включается в `dist` и не передаётся браузеру. Фото и фронтенд статические, `api/leads.mjs` исполняется как Vercel Function. На хостинге без Node API форма работать не будет.

Есть honeypot, ограничение размера, валидация, проверка Origin, таймаут и ограничение 5 попыток за 10 минут на IP в пределах одного экземпляра сервера. Для публичного запуска с большим трафиком настройте распределённое ограничение через firewall хостинга: память функции не общая между экземплярами. Повторная отправка той же заявки использует прежний random_id VK для защиты от дубликатов.

Источник API: https://github.com/VKCOM/vk-api-schema/blob/master/messages/methods.json

Слайдшоу обложки использует существующие локальные фотографии ЦАО, ЗАО и СЗАО. Источники и лицензии сохранены в `docs/ASSETS.md`. Видео не загружается. Переходы идут каждые 6,5 секунды, предусмотрены пауза и настройка уменьшения движения.
